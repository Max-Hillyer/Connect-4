# Connect 4

## Usage

Clone the repo
```bash
git clone https://github.com/Max-Hillyer/Connect-4
```
Create a venv and install the `simple_graphics` library
```bash
python -m venv venv
source venv/bin/activate
pip install simple-graphics-lib
```
run `main.py`
```bash
python main.py
```
